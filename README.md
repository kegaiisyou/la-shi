# 拉屎大作战

一个纯前端 H5 小游戏，单文件即可运行（双击 `index.html` 即可玩）。

## 运行

- 直接打开 `index.html`
- 或本地起静态服务：`python -m http.server 8000`，访问 `http://localhost:8000`

## 当前状态

- 点击 💩 累计分数，按平方曲线升级（`need(n) = 10 * n²`）
- 最高分存浏览器 `localStorage`（**仅本机有效，换设备就没了**）
- 「登录 / 注册」按钮是占位，尚未接入真正的账号系统

## 账号登录方案（待选择）

见与助手的对话说明。三种主流方案对比：

| 方案 | 跨设备 | 后端 | 成本 | 适合 |
|------|--------|------|------|------|
| A. 纯前端 localStorage | 否 | 无 | 0 | 只想本地存进度 |
| B. Supabase / Firebase 等 BaaS | 是 | 托管 | 免费额度 | GitHub Pages 静态站 |
| C. 自建后端（Node + SQLite + JWT） | 是 | 需服务器 | 需主机 | 完全自主可控 |

确定方案后再接入。
